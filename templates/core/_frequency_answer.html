{% comment %} A frequency (likert) answer: its label, then one squircle per option, the answer's filled. One color, so it shows where the answer sits and never labels the person. Takes `pairs` (likert_pairs), `value` (the stored option, a position in the list) and `score`. With a score (an instrument engine scored the item; NOM-035 gives 0–4) the squares run from the lowest score to the highest and the answer fills its score's square: NOM-035 reverses the scoring on some items, so the same "Siempre" can sit at either end. Without one, the squares follow the question's own option order. The stored value is never printed: it is a position, not a score. {% endcomment %} {% with first=pairs|first last=pairs|last %} {% for v, label in pairs %}{% if v == value %} {% if score is not None and score != "" %} {{ label }} {% for step in pairs %}{% endfor %} {% else %} {{ label }} {% for step, step_label in pairs %}{% endfor %} {% endif %} {% endif %}{% endfor %} {% endwith %}
