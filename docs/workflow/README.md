# Workflow Documents

This directory contains temporary workflow artifacts and reusable templates.

Use these files to think through changes before implementation, but do not keep feature-specific PRDs, test plans, or refactor plans forever.

Keep durable knowledge in:

- `docs/specs/`
- `docs/user/`
- `docs/adr/`
- tests

Delete temporary workflow documents after implementation once their durable value has been transferred.
